Ledger Link sends your World of Warcraft: Forever character, guild roster and raid boss pulls to Raid Ledger, so your roster, gear and raid history stay current without retyping anything.

Addons can't connect to the internet, so Ledger Link works like WeakAuras or Details! exports. It builds the data, compresses it into a single string, and shows it in a box. You copy the string and paste it into Raid Ledger.

Commands

CommandWhat it does
/rl export charYour gear, talents and raid/dungeon lockouts
/rl export guildYour guild roster (up to 2,000 members)
/rl export raidYour last 50 recorded boss pulls
/rl ruleset normal | pvp | rp | hardcoreSets your realm ruleset (do this once per character)
/rl guildnotes on | offAdds public notes to the guild export (off by default)
/rl raid / /rl raid clearShows or clears your recorded pulls
/rl statusShows your last export times

/ledgerlink works the same as /rl, in case another addon already uses /rl.

How to use it

  1. Type /rl ruleset normal (or pvp, rp, hardcore) once on each character.
  2. Run an export, for example /rl export char. The text is already selected, so press Ctrl+C.
  3. In Raid Ledger, open your character, choose Import string, and paste.

Big guilds: a guild with more than 250 members exports in pages. Use Next > to step through them, copy every page, and paste them all into the same import box, in any order.

Raid pulls: while the addon is loaded, it records each boss pull: the encounter, difficulty, kill or wipe, start and end times, and who was in the group. It keeps the newest 50. It does not record damage or DPS, because WoW: Forever doesn't let addons read the combat log.

Privacy

  • Officer notes are never read or exported, whatever your guild rank.
  • Public guild notes are only included if you turn them on with /rl guildnotes on.
  • Nothing leaves your game unless you copy a string and paste it somewhere yourself.

Status

This is an alpha for the WoW: Forever beta. If something breaks, please open an issue and include the Lua error text (if any) and your /rl status output.
